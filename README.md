# 🌌 EVENT HORIZON — MULTIVERSE ENGINE

**Explore the universe. Control cosmic forces. Discover the impossible.**

Event Horizon is an interactive 3D space sandbox built with HTML, CSS, JavaScript, and Three.js.

## ✨ Features
- Interactive 3D space exploration
- Multiple unique universes
- Black holes and planetary systems
- Starfighter pilot mode
- Planet selection and camera controls
- Cosmic disasters and shockwaves
- Time dilation and visual effects
- Radar and telemetry HUD

## 🎮 How to Run
1. Download `index.html`.
2. Open it in a modern web browser.
3. Explore the universe!

## 🛠️ Technologies
- HTML
- CSS
- JavaScript
- Three.js
